# Подготовка подключения hh.ru — 2026-10-04

Опубликованный URI: `https://31.129.108.20/api/v1/integrations/hh/callback`.
HTTPS проверен внешним запросом с проверкой сертификата, статус 200.
Страница честно сообщает, что аккаунт ещё не подключён. Это подготовка к регистрации приложения, не завершённая интеграция подбора.

## Опубликовано

- GET callback: справочная страница, обработка OAuth state/cookie, отказа, обмена кода и проверки аккаунта работодателя.
- POST `/api/v1/integrations/hh/connect`: только администратор своей компании; ключи обязательны.
- GET `/api/v1/integrations/hh/status`: доступность настройки для администратора.
- Одноразовый state на 10 минут, привязанный к браузеру и компании; шифрование токенов Fernet.
- Отдельный TLS proxy `academy-tls`, конфигурация `ops/hh-tls.compose.yml`, порт 443.
- Сертификат Let's Encrypt для IP, продление systemd `academy-cert-renew.timer` каждые 6 часов. Проверка `certbot renew --dry-run` успешна.
- Резервная копия backend: `/opt/backups/masshtab-academy/hh-bootstrap`; образ `masshtab-academy-backend:rollback-hh-bootstrap`.

## После одобрения hh.ru

На сервере безопасно настроить и передать в backend container переменные `HH_CLIENT_ID`, `HH_CLIENT_SECRET`, `HH_REDIRECT_URI`, `HH_USER_AGENT`, `HH_TOKEN_ENCRYPTION_KEY`. Последний ключ — отдельный Fernet key; хранить резервную копию, не менять без перешифрования токенов. Секреты не размещать в репозитории и чате. В текущем production compose эти переменные ещё не прокинуты; до настройки ключей connect возвращает 503.

Перед включением подключения обновить карточку интеграции frontend (сейчас прежняя заглушка), добавить HTTP → HTTPS перенаправление для маршрутов hh и отключить query-string access logs на HTTP frontend для callback. HTTPS callback уже исключён из access logs TLS proxy; uvicorn filter убирает query из callback access logs.

Следующие этапы не реализованы: обновление токенов, импорт вакансий/откликов, дедупликация кандидатов, сообщения, приглашения, отказы. Проверить ограничения и актуальные методы чатов hh.ru перед реализацией. В generic CRUD интеграций следует запретить ручную замену OAuth-служебных полей провайдера hh.ru.
