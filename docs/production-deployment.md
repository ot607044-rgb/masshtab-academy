# Публикация через GitHub

Источник кода — `main` в `ot607044-rgb/masshtab-academy`. Изменения сначала
проверяются и сохраняются коммитом в GitHub. Успешный push запускает
`.github/workflows/deploy.yml`: серверные тесты, сборку и браузерные тесты,
затем публикацию именно проверенного коммита.

На сервере применяется только `docker-compose.prod.yml` с `.env.prod` и
именем проекта `masshtab-academy`. Обычный `docker compose up` использует
режим разработки и для сервера не подходит. Не запускать старый
`auto-deploy.sh` и не удалять Docker volumes.

## Однократная настройка

- Установить `ops/academy-deploy-trigger.sh` в
  `/usr/local/sbin/academy-deploy-trigger` (владелец root, права 755).
- Создать отдельный SSH-ключ для Actions. В `authorized_keys` использовать
  `restrict,command="/usr/local/sbin/academy-deploy-trigger"` перед публичным
  ключом. Он принимает только `deploy <SHA>` текущей ветки `origin/main`.
- Сохранить приватный ключ в секрете репозитория `DEPLOY_SSH_KEY`,
  проверенную запись ключа сервера — в `DEPLOY_KNOWN_HOSTS`.
  Ключи и `.env.prod` в Git не добавлять.

## Проверки публикации

Скрипт блокирует одновременные релизы и отказывается затирать изменённые
отслеживаемые файлы. До миграций сохраняет дамп базы, uploads, исходники и
предыдущие образы в `/opt/backups/masshtab-academy/<release>`.

После сборки entrypoint обновляет схему Alembic. Проверяются `/health`,
авторизованные запросы к основным разделам и доступам, nginx и HTTPS callback.
Успех фиксируется в `/opt/masshtab-academy-deployed-commit` и журнале Actions.
Зелёный workflow означает прохождение проверок на сервере, а не только сборку.

При ошибке не восстанавливать базу автоматически: это может удалить новые
данные. Сначала изучить журнал Actions и `docker compose -p masshtab-academy
-f docker-compose.prod.yml --env-file .env.prod logs backend`. Предыдущие образы
сохранены с тегами `rollback-<release>`; возможность возврата проверяется с
учётом совместимости схемы. Старый дамп восстанавливается только при
необходимости и после сохранения текущей базы.
