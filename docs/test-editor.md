# Редактор тестов

В разделе «Материалы и тесты → Тесты» кнопка «Создать тест» открывает `/dashboard/tests/new`. Существующие тесты редактируются на `/dashboard/tests/:id`.

Слева находится структура вопросов; в центре — формулировка, тип, баллы, варианты и пояснение. Настройки и результаты вынесены во вкладки. Сохранение явное: неполные вопросы можно сохранить в черновике, публикация проверяет готовность. Добавление, дублирование и удаление применяются при сохранении. При ошибке введённые данные остаются в редакторе; успешно сохранённые вопросы учитываются при повторе операции. Предпросмотр выполняется локально и не вызывает API попыток.

API обновления теста теперь принимает явный null для очистки необязательных связей и ограничения времени; пропущенные поля не меняются.

Проверено 4 октября 2026: сборка frontend; 8 проверок редактора desktop/mobile; полный браузерный набор 42 passed / 6 skipped (отдельные интеграционные сценарии); 36 backend-тестов. Дополнительно на реальном изолированном preview PostgreSQL проверены создание, сохранение, перезагрузка, очистка времени и предпросмотр. Временный тест удалён.

Просмотр: http://localhost:5173/dashboard/tests/new. Локальный frontend использует существующий SSH-туннель к изолированной preview-базе. В preview обновлён только backend/app/api/v1/tests.py и перезапущен academy-ui-preview-backend-1.
